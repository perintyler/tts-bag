# TTS (Barry bag)

Text-to-speech via Piper — speak text aloud with configurable voices.

## Tools

- `speak` — speak text aloud using text-to-speech
- `enable_voice_mode` — enable voice mode so speak calls produce audio
- `disable_voice_mode` — disable voice mode and stop playback
- `toggle_voice_mode` — toggle voice mode on or off
- `stop_speaking` — stop current playback and clear the speech queue
- `set_voice` — change the voice model used for TTS
- `list_voices` — list available Piper voice models
- `voice_status` — check TTS system status (voice mode, current voice, queue, installation)
